##### Visualización 3D de proteinas

AminoFold3D es un portal web que permite visualizar una proteina en 3D a partir del nombre de una proteina o su secuencia FASTA. Para poder predecir la estructura geometrica en 3D se usa el sistema de inteligencia artificial AlphaFold.

El problema surge de la escasez de programas que realicen esta tarea y de la barrera de entrada que supone para usuarios del CIMUS llevar a cabo este tipo de tareas debido a su falta de familizarización en el entorno informático.

El principal objetivo es ofrecer una web en la que cualquier investigador pueda acceder para poder obtener las estadísiticas y la visualización 3D de la proteina deseada de forma simple.

VIDEO

## Características principales

* **Visualización 3D de proteinas** --> Modelo 3D de la proteina completamente interactivo.
* **Gestor de trabajos** --> Se muestra un historial de los trabajos enviados y el estado de cada uno.
* **Amplio rango de datos**--> Se ofrece una gran cantidad de datos útiles para los estudios de la proteina predecida.
* **Asistente AI**--> Chatbot AI asistente para responder las preguntas del investigador usuario.
* **Comparador de proteinas** --> Permite comparar 2 proteinas, ofreciendo ambas visualizaciones en 3D, un resumen comparativo y diferencias clave entre ellas
* **Descarga de ficheros de información variada** --> Se le permite al investigador descargar documentos del tipo .pdb, .mmcif, JSON de confianza y logs completos.
